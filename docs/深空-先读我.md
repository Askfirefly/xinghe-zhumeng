# 先读我 · 深空 + 行星 交付包 v1

分工：本包 = **深空背景 + 太阳 + 八大行星 + 月球**（含大气/环/昼夜/程序化气态条带）。
队友主包《星河追梦》提供 look 规格、starfield 底稿与单文件构建约定，本包已全部对齐。

## 1. 看成片（30 秒）

双击 `成片/深空太阳系.html`。**单文件、全离线**：three.js r185 与全部贴图已内联（5.6 MB），
无需服务器、无需网络。推荐 Chrome / Edge / Safari 16+。

- 拖拽旋转、滚轮缩放、点击行星或底栏按钮聚焦；
- 底栏：暂停 / 减速 / 加速 / 轨道线 / 标签 / 全景；
- 聚焦后右上信息面板给出真实直径/轨道/周期/温度与一句看点；
- 低配机器加 URL 参数：`深空太阳系.html?q=low`（或 `mid`，默认 `high`）。

验收结论：1080p 默认画质 **60 fps**，console **零报错零警告**；
多机位截图见 `截图/`（全景 / 地球 / 土星 / 木星 / 银河 / 太阳特写）。

## 3. 复现构建

```bash
cd 源码 && node build.js        # 产出 dist/scene.html
# 可选：重新生成贴图 b64（需 python + Pillow）
python tools/tex2b64.py
```

## 4. 与主包合并的约定

1. **look 规格对齐**：AgX tone mapping、曝光基准 1.3（自适应 ±12%）、grain 0.02、
   vignette 0.24、色温基准 5600K（albedo 以中性白 authored，后处理不加 WB 矩阵）。
   参数集中在 `src/app.js` 的 `compMat` uniforms，改一处即全局生效。
2. **尺度**：1 AU = 40 世界单位；半径为视觉尺度（非线性），周期/倾角/自转周期为真实值
   （自转视觉加速 20×）。合并时若主包另有尺度，改 `AU` 与 `BODIES.r` 两处即可。
3. **大尺度渲染两件套**（合并后必须保留，否则近远裁剪互撕）：
   `logarithmicDepthBuffer: true` + 浮动原点（相机恒在原点，`universe.position = -camWorld`）。
   自定义 ShaderMaterial 必须插 logdepth 四 chunk，且 vertex 先 `#include <common>`。
   见 `可复用片段/logdepth-chunks.js`、`floating-origin.js`。
4. **单文件合并方式**：沿用主包 build 约定 —— shell.html 占位 + `/*__THREE__*/`（CJS shim）
   + `/*__APP__*/` + 贴图 `<script type="text/plain">`。本包 build.js 与主包同构，可直接拼。
5. **调试句柄**：`window.__solar`（focus/home/setCam/setDays/setSpeedIdx/pause/simDays/
   focusKey/bodies/renderer/camera/scene/universe），验收与主包联调都用它。

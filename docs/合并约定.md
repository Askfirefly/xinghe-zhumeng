# 合并约定

两个场景最终要拼成一条片子。这份文档是唯一的对齐依据，改参数先改这里。

---

## 1. 视觉规格（look spec）

两边必须完全一致，否则拼起来像两个人的片子。

| 项 | 值 | 落地位置 |
|---|---|---|
| 色调映射 | **AgX**（three r180 实现） | `ground`: `post` pass；`space`: `compMat` |
| 曝光 | 基准 **1.3**，自适应 ±12%（clamp 0.88–1.12） | 同上 |
| 颗粒 | **0.02** | 后处理最后一环 |
| 暗角 | **0.24** | 后处理最后一环 |
| 色彩空间 | albedo 以中性白 authored，后处理不加白平衡矩阵 | — |
| 参考色温 | 5600 K | — |

> 深空那边参数集中在 `space/src/app.js` 的 `compMat` uniforms，改一处全局生效。

---

## 2. 尺度

- **深空**：1 AU = 40 世界单位；行星半径是**视觉尺度**（非线性，为了看得见），
  轨道周期 / 倾角 / 自转周期是真实值（自转视觉加速 20×）。
- **地面**：真实米制。公路宽 7.6 m，长征五号高约 57 m，发射台本地坐标在 (62, 0, -168)。
- 两边不共享世界坐标。合并时靠**转场**衔接，不是靠缩放。

### 大尺度渲染两件套（深空必须保留）

```js
renderer = new THREE.WebGLRenderer({ logarithmicDepthBuffer: true })
universe.position.copy(camera.position).negate()   // 浮动原点
```

自定义 `ShaderMaterial` 必须插 logdepth 四个 chunk，且 vertex 里先 `#include <common>`。
见 `snippets/logdepth-chunks.js`、`snippets/floating-origin.js`。

---

## 3. 构建约定

两边用**同一套**单文件构建方式：

```
shell.html（HUD/面板/占位）
  ├── /*__THREE__*/   ← three.cjs（CJS shim）
  ├── /*__APP__*/     ← app.js
  └── <script type="text/plain"> 贴图 base64
```

`node build.js` 产出 `dist/scene.html`，**不需要 npm 依赖**（three 已在 `vendor/`）。

已验证：两边从源码重建的产物与仓库里的发布文件**逐字节一致**。

## 4. 运行时接口

### 地面（`ground`）

```js
window.__rocketU      // { focus }              当前聚焦部件
window.__rocketParts  // [7] { name,label,obj,base,off,t,target,inner,el }
window.__towerU       // { open, target }       塔臂 0..1（1 = 张开 90°）
window.__rocketGroup  // 整支火箭
window.__pad          // 整个发射工位
window.__rocketUpdate(dt)   // 每帧推进所有动画
```

### 深空（`space`）

```js
window.__solar        // { focus, home, setCam, setDays, setSpeedIdx, pause,
                      //   simDays, focusKey, bodies, renderer, camera, scene, universe }
```

## 5. 转场镜头（还没做）

目标镜头：**塔架仰视 → 拉出大气层 → 星空 → 太阳系**。

建议实现顺序：

1. 地面场景相机沿 Y 上升，同时 `fog`/`exposure` 渐变（0.6 s）
2. 地面层淡出，深空层淡入（交叉溶解，不是硬切）
3. 深空场景从「地球附近」的机位开始，再 `__solar.setCam` 推到目标

⚠️ 不要试图把两个 WebGL 场景塞进同一个 canvas —— 它们的后处理管线、深度策略、
曝光控制都不一样，硬拼必炸。用两层 canvas + CSS 交叉溶解最稳。

---

## 6. 改动流程

1. 改 `ground/src/app.js` 或 `space/src/app.js`
2. `node build.js` 重新生成
3. **先跑 `node tools/errcheck.js`**（shader 编译失败时画面上只表现为"物体消失"）
4. 出图对比：`node tools/eval_shot.js out.png "" "day=0.487&cam=..."`

改视觉参数时，**先改这份文档，再改代码**。

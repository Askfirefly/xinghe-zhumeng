## 1. P0 · 发射流程（阿香下一步明确要的）

**现状**：只有第 1 步（塔臂张开）做完了。火箭本体纹丝不动。

**目标**：一条完整、可复放的发射序列。

建议做成一个显式状态机，别散在回调里：

```js
const SEQ = ['idle', 'armsOpen', 'translate', 'ignition', 'liftoff', 'separation'];
const launch = { phase: 'idle', t: 0 };   // t = 当前阶段已过秒数
```

| 阶段 | 时长 | 做什么 | 验收 |
|---|---|---|---|
| `armsOpen` | 3 s | `__towerU.target = 1`（**已完成**） | 两臂到 90° |
| `translate` | 2.5 s | 火箭 + 发射台一起沿 `-z` 平移 8 m | 火箭离开塔架包围 |
| `ignition` | 2 s | 尾焰起燃、点光源亮起、地面反光 | 画面底部有暖光 |
| `liftoff` | 12 s | `y += v·dt`，`v` 从 0 加速到 60 m/s | 出画 |
| `separation` | — | 助推器外抛 / 抛整流罩 / 级间分离 | 见 1.4 |

### 1.1 底座外移（`translate`）

⚠️ **注意**：现在火箭（`rocketGroup`）是挂在 `group`（发射工位）下的子节点，
发射台面是 `parts` 里合并进去的**静态几何**。所以只动 `rocketGroup` 会出现
"火箭飘起来、台子还在原地"。

两个选择：
- **省事**：把发射台面那几块几何单独拆成一个 `TableGroup`，和火箭一起平移（推荐）
- **取巧**：只平移火箭，把台面用烟雾挡住（`ignition` 阶段的烟正好可以）

```js
// 平移要沿工位自己的局部轴（group 绕 Y 转了 -0.30 rad）
const dir = new THREE.Vector3(0, 0, -1);      // 局部 -z = 朝公路方向
rocketGroup.position.copy(start).addScaledVector(dir, 8 * ease(t / 2.5));
```

### 1.2 尾焰（`ignition` → `liftoff`）

用加法混合的锥体 + 噪声滚动，不需要粒子系统：

```glsl
// 单锥：底部亮、上端收、随时间抖
float n = fbm(vec2(angle * 3.0, vUv.y * 6.0 - uTime * 9.0));
float body = pow(1.0 - vUv.y, 1.6) * (0.75 + 0.45 * n);
vec3 col = mix(vec3(1.0, 0.95, 0.75), vec3(1.0, 0.45, 0.10), vUv.y) * body * 6.0;
gl_FragColor = vec4(col, body);
```

- 芯级 2 个喷管、助推 4 个，各挂一个锥（长度随 `throttle` 变化）
- 同时加 1 个 `PointLight(0xffb060, 900, 120)` 放在喷口下方，**强度随油门**——
  这是"点火有重量感"的关键，比焰本身重要
- 地面加一层"呼吸"的反光亮斑（贴地 plane，加法混合，随时间抖动）

### 1.3 起飞

```js
// 真实一点的曲线：前 2 秒慢（推力爬升），之后线性加速
v = 3 + 5.5 * Math.max(0, t - 1.5);
y += v * dt * 0.3;   // 缩放系数，别用真实 1:1，太快
```

镜头：起飞时把相机自动切到仰视跟拍（复用 `cam`/`yaw`/`pitch` 的插值），
或者干脆锁定 `lookAt(rocket)`。

### 1.4 分离（部件已经给你拆好了）

这是这套模型最大的价值：**7 个部件是独立的，内部结构也在**，直接按 `off` 方向推就行。

```js
// 助推器分离：沿各自径向外推 + 下坠
boosters.forEach((b, i) => {
  const dir = new THREE.Vector3(b.base.x, 0, b.base.z).normalize();
  b.obj.position.addScaledVector(dir, 6 * t);
  b.obj.position.y -= 4 * t * t;
  b.obj.rotation.z += 0.02 * t;      // 翻滚
});

// 抛整流罩：两瓣张开（需要先把 fairing 的 shell 拆成左右两半）
// 级间分离：upper 向上顶出，core 继续
```

⚠️ **抛整流罩需要改模型**：现在整流罩是**整体**的。要两瓣张开，
得把 `pFair` 的 shell 拆成 `fairL` / `fairR` 两个 Group（以 x=0 为切面），
`decalFlag` / 字标只贴在其中一瓣上。

## 2. P1 · 科普层（阿香最初的目标之一，现在几乎是空的）

**现状**：只有部件悬停标签（名称 + 尺寸）。没有数据、没有解释、没有导览。

**目标**：让一个不懂航天的人看 3 分钟能明白"这玩意多重、多大、怎么飞上去的"。

建议做三层，从便宜到贵：

### 2.1 数据卡（半天，性价比最高）

点开某个部件时，右侧浮出一张卡片：

```
芯一级
5 m × 31 m · 干重约 17 t · 推进剂约 150 t（液氧/液氢）
2 × YF-77 氢氧发动机 · 单台真空推力 700 kN
```

数据来源：公开资料（CZ-5 起飞质量 869 t，LEO 25 t，GTO 14 t）。
**注意用"约"，并且给出来源**——科普内容写错比不写更糟。

### 2.2 结构标注（1–2 天）

在"外壳半透明"状态下，给内部件也加标签：
`液氧箱` / `液氢箱` / `共底` / `涡轮泵` / `摆动伺服` / `增压气瓶`。
实现方式完全复用现在的 `rocketParts[].el` 那套 DOM 标签，只是挂到 `inner` 的子物体上。

⚠️ 现在 `inner` 里的件**没有名字**，需要在建模时打 `mesh.userData.label`。

### 2.3 时间轴导览（3–5 天）

一条底部时间轴，拖动可以走完：**加注 → 塔臂张开 → 点火 → 起飞 → 分离 → 入轨**。
每一段自动切镜头 + 配一段解说字幕。这基本等于把发射流程再包一层 UI。

## 3. P2 · 视觉打磨（有明确缺陷，不是"还能更好"）

| 问题 | 现象 | 怎么做 |
|---|---|---|
| **远景 popping** | 远处树/护栏突然出现 | 现在按距离直接 hide；改成按帧渐隐 + 提前 20% 距离开始淡 |
| **雨不打湿镜头** | 屏幕水滴不随视角/时间积累 | 加一张"湿度"场：`wet += rain*dt - evap*dt`，控制水滴密度和模糊强度 |
| **没有环境音** | 只有 BGM | 雨声（白噪 + 带通）、远处海浪、发射低频（<60 Hz 正弦 + 噪声） |
| **发射台无烟** | 点火时应该白烟滚滚 | 和尾焰同一套 march 思路做 2D billboard 烟（加法/普通混合各一层） |
| **火箭底部悬空感** | 现在喷管离台面还有空隙 | 加导流锥 + 火焰反射，或者把喷管往下延长 1.5 m |

## 5. 已知的坑（别重复踩，每条都是我们真踩过的）

| 坑 | 现象 | 解法 |
|---|---|---|
| **GLSL 保留字** | `float patch = ...` → 整个 shader 编译失败，画面上只表现为"那个物体不见了" | `patch input output filter sample smooth active common partition resource superp template this` 都不能当变量名 |
| **不看 console** | 上面那个 bug 我们带了两轮才抓到 | 改完 shader **第一件事**跑 `node tools/errcheck.js` |
| **几何坐标双重偏移** | 部件"自己散开"，代码怎么看都对 | 几何按绝对坐标建 + Group 又有 position → 双倍位移。**用包围盒数值验证**，别用眼睛 |
| **反射 pass 顺序** | 整个场景消失，只剩天空里的虚线 | 主渲染 2 帧后再开反射 pass |
| **canvas 透明贴图发黑** | 文字后面有个黑方块 | `material.alphaTest = 0.45` |
| **自发光当灯用** | 整场过曝成白 | 自发光只做"看起来亮"，不参与照明 |
| **uniform 数组长度不一致** | 直接崩 | JS 侧长度必须和 shader 里 `uX[64]` 完全一致 |

## 6. 和"太阳系"项目的接口

那边在做太阳系，我们这边是地面。两边最终要拼成一条片子。建议：

1. **共享 look spec**（已在 `03-文档/给太阳系创作者的Agent建议.md` 里）：
   AgX、曝光 1.3、颗粒 0.02、暗角 0.24、5600K
2. **过渡镜头**：需要一个"从塔架仰视 → 拉出大气层 → 星野"的连续镜头。
   我们现在没有大气层外的部分，这个镜头得由太阳系那边提供星空/地球弧线。
3. **接口建议**：把我们的场景导出成一段带 alpha 的前景层，叠在他们的星空上，
   比"两个 WebGL 场景硬切"稳得多。

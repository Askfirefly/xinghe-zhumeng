# 实现说明 · 深空 + 行星

对应源码：`源码/src/app.js`（行号为 v1 交付时点）。

## 1. 尺度与坐标

- `AU = 40`；`BODIES` 中 `r/d` 为视觉尺度（太阳 8、地球 1、木星 3.6…），
  `T/rot/tilt` 为真实值（天/天/度）。月球 `parent:'earth'`，d=2.6。
- 世界坐标用 JS double 保存（`bodyGroups[key].worldPos`），渲染空间 = 世界 - 原点。
- **浮动原点**：每帧 `origin.copy(camWorld); universe.position = -origin; camera.position=(0,0,0)`。
  相机永远在原点 →  view 矩阵无大数，配合 log 深度解决 0.02..5000 的同框裁剪。
- `camera.near = max(0.02, cam.r*0.0015)` 随焦距动态更新（变化 >2% 才重建投影矩阵）。
- 自转视觉加速 20×（真实自转在常用流速下不可见）；云层再 ×1.12 产生差速。

## 2. 后处理链（手动实现，不依赖 addons）

```
scene → rtScene(HalfFloat, MSAA 4)
      → brightMat(knee 2.6) → rtBrightA(半分辨率)
      → blur H/V ×2（ping-pong A/B）→ rtBrightA
      → downMat → rtQuarter(1/4) → blur H → rtQuarterB → blur V → rtQuarter
      → lum8Mat(8×8 log 亮度) → rtLum8
      → adaptMat(时间平滑, 读 prev 写 cur, A/B ping-pong) → rtLumA/B
      → compMat: bloom 合成 + 自适应曝光(clamp 0.88–1.12) + AgX + vignette 0.24
                 + lin2srgb + grain 0.02(显示空间)
```

- AgX 矩阵/contrast 曲线逐字移植 three r185 tonemapping chunk（sRGB→Rec2020→AgX→回 sRGB）。
- 曝光基准 1.3；自适应目标 0.10 平均亮度，`pow(...,0.85)`，±12% clamp（look 规格）。
- **踩坑**：quarter blur 曾读 rtQuarter 写 rtQuarter → GL feedback loop（console 每帧一条
  `GL_INVALID_OPERATION`）。任何 pass 的 src 与 dst 必须不同 RT；时间自适应同理用 A/B。
- **踩坑**：AgX 对暗部提升很大（linear 0.12 → 显示约 0.55 灰）。银河乳光强度必须按
  "显示目标"反推：band 0.032 / halo 0.010 / neb 0.07，否则深空变灰雾。

## 3. 天体 shader 清单

| 天体 | 方案 |
|---|---|
| 星空+银河 | 4 层 hash 星点（cell 内抖动、星等幂律、色温 tint）+ 倾斜银道面乳光/尘 lane/星云斑；银河经度用 `vec2(cos,sin)` 圆周坐标采样避 ±π 缝 |
| 太阳 | 黑体色 granulation（双 fbm）+ 临边昏暗 + HDR 5.0；日冕为加法 billboard：噪声射线 + 边缘 `1-smoothstep(0.75,1,r)` 归零防露圆边界 |
| 气态四行星 | FBM 纬向条带 + 各向异性 warp（沿经度拉伸）+ 大红斑/大暗斑椭圆涡旋；**经度一律圆周坐标进噪声**（线性 atan 坐标会有竖直缝） |
| 地球 | 昼/夜贴图 mix（夜面城市灯光）+ 海洋镜面高光 + 独立云层球 + Rayleigh/Mie 单散射大气壳 |
| 土星环 | 径向密度波 + Cassini/Encke 缝 + 前向散射 + 行星本影投影 |
| 岩质行星/月球 | MeshStandardMaterial map+bump（真实贴图） |

所有自定义 ShaderMaterial 均插 logdepth 四 chunk（vertex 先 `<common>`）。

## 4. 交互与 UI

- 聚焦阻尼 `k = 1-exp(-dt*4.2)`；`minR()` 按天体半径防穿模；点击拾取用 raycaster。
- 标签防叠：视直径 <3px 且未聚焦 → 隐藏；按 y 排序强制 24px 间距；
  落入 HUD 透明文字矩形区（x<480, y<310）→ 隐藏（HUD 无背景，标签会透叠）。
- 画质档 `?q=low|mid|high`：DPR cap 1/1.5/2、MSAA 0/2/4、星层 2/3/4。
- `window.__solar` 调试句柄见先读我 §4.5。

## 5. 性能

1080p/high 实测 60 fps（M 系列 Mac / 独显 PC 同档）；太阳特写 58–60 fps。
开销大头：rtScene MSAA + 半分辨率 bloom ×4 pass + 大气壳 overdraw。低配走 `?q=low`。

## 6. 本轮验收修复记录（v1 内）

1. logdepth vertex chunk 缺 `<common>` → `isPerspectiveMatrix` 编译错误。
2. 气态行星经度线性 atan 进噪声 → 球面竖直缝；改圆周坐标。
3. 日冕 streaks 衰减过慢且边缘不归零 → 中距离整屏灰雾 + 圆边界；改 exp(-r*5..7) + rim 归零 + uScale 3.4→2.6。
4. 太阳 HDR 16 →  granulation 全白；降 5.0 并加临边色偏。
5. 银河强度按 AgX 暗部提升反推下调；尘 lane 加第二重 fbm 打断斜向条纹。
6. quarter blur 自读自写 feedback loop → 增 rtQuarterB ping-pong，并补齐 V 向 blur。
7. 标签透叠 HUD → 矩形排除区。
